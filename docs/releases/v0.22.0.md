# AYX-RS v0.22.0

This release hardens operator-facing errors and completes the Alteryx One
workspace command hierarchy refresh.

## Upgrade notes

- **BREAKING:** `ayx one workspace` now groups active-workspace operations
  under `config`, `members`, `groups`, `cloud-configs`, and `transfer`. The
  previous flat verbs have been removed; consult `ayx one workspace --help`
  and update scripts to the nested command paths.
- The legacy `ayx one flows` namespace is removed. Use `ayx one workflows`
  for cloud-native workflow operations.
- Human-readable failures now show an envelope-owned error block before any
  recovered partial records. Provider response bodies, request IDs, headers,
  and diagnostic URLs remain available only in recursively redacted JSON/YAML
  output.
- Unknown list/detail response wrappers no longer look like successful empty
  results. Text output identifies safe wrapper keys and states that the
  installed CLI does not recognize the service shape.

## Validation

The release is gated by generated command-surface verification, locked
workspace formatting, Clippy, tests, and a production docs build. The Windows
Alteryx One read sweep records the selected binary identity and can require the
expected release version with `-ExpectedVersion`.
