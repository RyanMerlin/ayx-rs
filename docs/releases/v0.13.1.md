# AYX-RS v0.13.1 Release Notes

## Highlights

- **Bare command groups now render real clap help.** `ayx one` and the other command groups show Usage, Commands, and Options instead of a hand-written flat list, while groups with real defaults retain their behavior.
- **The `one` subtree has complete one-line command descriptions.** `ayx one <group> --help` and the command catalog now provide useful summaries for every One command.
