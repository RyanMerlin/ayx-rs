# AYX-RS v0.21.0

This release delivers the Phase 3 operator-intake output contract and the
canonical Alteryx One Job Library command family.

## Job Library commands

Use the new Jobs surface for aggregate Job Library entries and their child runs:

```text
ayx one jobs <JOB-ID>
ayx one jobs runs <JOB-ID>
ayx one jobs execute --body request.json
```

`jobs runs` displays the complete lifecycle, status, timing, warning/error, and
execution metadata returned for every child run. JSON remains recursively
redacted and retains the provider response without presentation-only labels.

`ayx one job-groups` remains callable as a hidden compatibility namespace for
this release cycle. It is excluded from help, catalog, and normal discovery.
There is no singular child-run detail command because the vendor exposes a
child-run collection and only a status-only direct child route.

## Output and operator intake

- Text and JSON use aligned canonical command labels.
- Human output includes remediation and operator-readable timestamps; machine
  output retains exact redacted timestamps.
- Named output collections remain explicit opt-in projections.
- Agent Assets remains hidden because its API contract does not support bearer
  authentication for the supported credential profiles.

## Validation

The release is gated by formatting, generated command-surface validation,
locked workspace Clippy and nextest, audit, release builds, and live Alteryx One
validation from the packaged release candidate.
