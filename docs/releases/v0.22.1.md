# AYX-RS v0.22.1

Security-only patch release.

## Security

Updates the locked TLS dependency graph from `rustls` 0.23.37 to 0.23.45,
resolving RustSec advisory `RUSTSEC-2026-0285` (TLS 1.3 handshake messages
accepted across encryption-level boundaries).

No command-surface or configuration behavior changes are included.

## Validation

The patch is gated by `cargo audit --deny warnings`, locked workspace tests,
Clippy, formatting, generated command-surface verification, and the docs-site
build.
