# AYX-RS v0.11.2 Release Notes

## Highlights

- **The first Windows release binary is now published.** A hardened Windows build job produces `ayx-x86_64-pc-windows-msvc.zip` and connects it to checksums, Sigstore signing, and SLSA attestation, fixing the PowerShell installer's prior 404.
- **The TUI v2 resource-browser preview is available behind `AYX_TUI_V2=1 ayx tui`.** It currently browses Alteryx One flows end-to-end; the existing `ayx tui` behavior is unchanged without the flag.
